# General Health Query Chatbot

## Task Objective

The objective of this project is to develop an AI-powered health chatbot capable of responding to general health-related queries. The chatbot provides informational responses based on user input and demonstrates the application of Natural Language Processing (NLP) in healthcare assistance.

## Dataset Used

This project does not rely on a traditional machine learning dataset. Instead, it utilizes a Large Language Model (LLM) API to generate responses for user health queries.

## Models Applied

* Mistral AI / Large Language Model (LLM)
* Natural Language Processing (NLP)

## Key Results and Findings

* Successfully developed an interactive chatbot capable of answering general health questions.
* Implemented conversational interaction through a command-line interface.
* Demonstrated the practical use of AI and NLP for healthcare information assistance.
* Improved user engagement by providing real-time responses to health-related queries.

## Technologies Used

* Python
* Requests Library
* Mistral AI API
* NLP Concepts





# House Price Prediction

## Task Objective

The objective of this project is to predict house prices using machine learning techniques based on property characteristics such as living area, number of bedrooms, neighborhood, overall quality, bathrooms, and garage area.

## Dataset Used

* Ames Housing Dataset (Kaggle)
* Total Records: 2930
* Features: 82

## Models Applied

* Linear Regression
* Gradient Boosting Regressor

## Key Results and Findings

* Performed data preprocessing, feature selection, and feature scaling.
* Trained and evaluated multiple regression models.
* Evaluated model performance using Mean Absolute Error (MAE), Root Mean Squared Error (RMSE), and R² Score.
* Generated Actual vs Predicted Price visualizations.
* Gradient Boosting Regressor achieved better predictive performance compared to Linear Regression.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-learn
* Actual vs predicted





# Stock Price Prediction

## Task Objective

The objective of this project is to predict the next day's stock closing price using historical stock market data and machine learning techniques.

## Dataset Used

* Historical stock market data retrieved using the Yahoo Finance API (yfinance)
* Stock selected for analysis: Apple (AAPL)

## Models Applied

* Linear Regression
* Time Series Forecasting Techniques

## Key Results and Findings

* Collected and analyzed historical stock price data.
* Performed preprocessing and feature engineering on stock market indicators.
* Trained a machine learning model to predict future stock closing prices.
* Visualized actual and predicted stock prices for performance comparison.
* Evaluated prediction accuracy using MAE and RMSE metrics.

## Technologies Used

* Python
* yfinance
* Pandas
* NumPy
* Matplotlib
* Scikit-learn
