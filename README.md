# House Price Prediction

## Objective

The goal of this project is to predict house prices using machine learning regression models.

## Dataset

Ames Housing Dataset from Kaggle

## Features Used

* Gr Liv Area
* Bedroom AbvGr
* Neighborhood
* Overall Qual
* Full Bath
* Garage Area

## Models Applied

1. Linear Regression
2. Gradient Boosting Regressor

## Evaluation Metrics

* Mean Absolute Error (MAE)
* Root Mean Squared Error (RMSE)
* R² Score

## Visualizations

* Actual vs Predicted House Prices
* Feature Importance

## Files

* house_price_prediction.py
* AmesHousing.csv
* output graphs

## Results

Gradient Boosting Regressor achieved better performance compared to Linear Regression for predicting house prices.
